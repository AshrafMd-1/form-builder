# Form Builder

> **Archived** — This project was developed during a web development course. The backend is currently non-functional and the repository is no longer actively maintained.

A custom form builder designed to create unique forms, featuring options like radio buttons, range sliders, and a live preview.

## Tech Stack

- **React 18** with **TypeScript**
- **Tailwind CSS** for styling
- Create React App

## Features

- Add and configure form fields (radio buttons, range sliders, and more)
- Live form preview
- Custom form structure without relying on a form library

## Getting Started

```bash
npm install
npm start
```

The app runs at `http://localhost:3000`.

## Build

```bash
npm run build
```

## Notes

This was a learning project. The frontend is functional but the backend integration is incomplete.
